# Brief 3 - Route planner

Standalone implementation for THRESHOLD Brief 3. It turns Interest Tags, a time budget, and a Persona into an ordered Red Fort walk.

## Run

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. The root route redirects to `/site/red-fort/plan`.

## Checks

```bash
pnpm typecheck
pnpm test
pnpm verify
pnpm build
```
